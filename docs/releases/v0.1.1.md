# v0.1.1

Patch release. All packages move to 0.1.1 in lockstep; the only substantive
change is in `@remelondb/core`.

## Fixed

- `@remelondb/core/react` was missing from the published package. The
  subpath (added in 0.1.0 with `useDatabaseState`) existed in the source
  exports map, but the build config never emitted `dist/react/` and
  `publishConfig.exports` never listed the subpath, so the published
  tarball had neither the files nor the export. Both are fixed;
  `import { useDatabaseState } from '@remelondb/core/react'` now works
  from the registry package.

## Release workflow

- A failing `npm publish` for one package no longer aborts the loop;
  remaining packages still publish and the job fails at the end.
