# v0.1.5

Patch release. All packages move to 0.1.5 in lockstep; the substantive
change is in `@remelondb/nestjs`.

## Fixed

- The NestJS module builds its own sync engine and passed only Zod
  validation into it, so engine table config such as `appendOnly` could
  not reach the served `/sync/push` at all. An app could configure
  `appendOnly` on an engine of its own, test against that engine, and
  run the module's unprotected engine in production. `RemelonSyncModule`
  now takes `tableOptions`, per-table engine config beyond validation:

  ```ts
  RemelonSyncModule.forRootAsync({
    useFactory: () => ({
      store,
      tables: { review_events: ReviewEvent },
      tableOptions: { review_events: { appendOnly: true } },
      scopeFrom,
    }),
  });
  ```

  Validation still always comes from `tables` and cannot be overridden.
  Conformance case 13 below now exercises this over real HTTP.

## Added

- Conformance case 13: a write to an existing id in a table declared
  `appendOnly` is rejected by id and the stored row is unchanged. It is
  opt-in — a backend declares the table through `appendOnly` in its own
  `registerServerConformance` call — which is the point: the case runs
  against the backend's real registration, so a transport that drops
  engine config on the way to its endpoints fails it. The memory-store
  engine, the Drizzle store, the reference server and the NestJS module
  all run it.

## Model

- The Quint model gains a `SILENT_DROP` fault switch: a server that
  applies less than it reports as accepted. Turning it on violates the
  convergence invariants in under a second, with the phantom-record
  trace as the counterexample. "Refusals are never silent" was a rule
  the model previously assumed — the two sets were one expression — and
  is now a rule it checks.

## Docs

- The backend reference and the nestjs README state the rule that made
  this a trap: the module builds its own engine, so config not passed
  through the module does not exist on the served endpoints.
- `sync-wire.md` §7 lists cases 11 to 13, which had shipped without
  reaching the checklist.

## Breaking

- None.
