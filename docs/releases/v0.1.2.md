# v0.1.2

Patch release. All packages move to 0.1.2 in lockstep; the substantive
changes are in `@remelondb/driver-web`.

## Fixed

- The published package now contains the shared-worker entry, and the
  driver's worker URLs point at the built files. Consuming
  `shared: true` from the registry previously failed at build time with
  Vite, or hung silently in dev.
- A shared worker that never starts now rejects `open()` with an
  actionable error instead of hanging: script load failures fail
  immediately, and a new `openTimeoutMs` option (default 15s) bounds
  the wait for a broker that loaded but never answers.

## Docs

- driver-web README gained a Bundlers section: Vite consumers need
  `optimizeDeps.exclude` for the driver chain.

## CI

- The Vite consumer smoke (packed tarballs, build and dev server,
  single-tab and shared two-tab) now runs on every relevant push.
